# Data Dictionary

This document describes the analysis-ready inputs, temporal-disaggregation inputs and outputs, and derived variables used in the public reproducibility pipeline.

## Naming conventions

Several analytical variables retain Portuguese names because the public scripts reproduce the validated empirical pipeline without renaming model inputs.

Common suffixes and prefixes:

| Element | Meaning |
|---|---|
| `LN_` | Natural-log transformation or the transformed log-compatible series used in the validated input |
| `_X13` | Seasonally adjusted using X-13-ARIMA-SEATS |
| `SA` | Santo Antônio |
| `BM` | Belo Monte |
| `D_` | Dummy / indicator variable |
| `L1`, `L2`, etc. | One-month, two-month, etc. lag in output tables or model notation |
| `DC` | Denton–Cholette |
| `CL` | Chow–Lin |
| `FERN` | Fernández |

The date column `Data` represents the first day of each monthly observation.

### Regime dummies generated by the ARDL scripts

These variables are generated programmatically and are not required as columns in the input workbooks.

| Variable | Plant | Definition |
|---|---|---|
| `D_2017` | SA | 1 from February 2017 onward; 0 otherwise |
| `D_2023` | SA | 1 from June 2023 onward; 0 otherwise |
| `D_2023` | BM | 1 from October 2023 onward; 0 otherwise |
| `D_2024` | BM | 1 from August 2024 onward; 0 otherwise |

The indicators enter the validated ARDL specifications as fixed, non-lagged regressors.

## 2. Temporal-disaggregation input files

Files:

- `data/01_monthlyization/ARQ_XLSX_SA.xlsx`
- `data/01_monthlyization/ARQ_XLSX_BM.xlsx`

### Worksheet `Receita_TRI`

This worksheet contains quarterly company financial flows.

| Field | Description |
|---|---|
| `Ano` | Year |
| `Trim` | Quarter |
| `Usina` | Plant code (`SA` or `BM`) |
| `Serie` / financial-series field | Financial-flow label |
| `Valor` / value field | Quarterly financial value in the monetary scale preserved from the source financial statements |

The input contains two financial series used by the public script:

| Internal series | English description | Role |
|---|---|---|
| `Receita_Vendas` | Sales revenue | Main revenue measure used in the financial-transmission model |
| `Energia Comprada Revenda` / standardized `Energia_Comprada` | Purchased energy for resale | Used to derive the monthly purchased-energy flow and net-revenue series |

Financial information originates from publicly available financial statements of **Santo Antônio Energia** and **Norte Energia S.A.** The monetary scale in the input workbook is preserved rather than rescaled by the public script.

### Worksheet `Energia_MES`

| Field | Description |
|---|---|
| `Ano` | Year |
| `Mes` | Month |
| `Usina` | Plant code |
| `Energia_Base_MWh` | Monthly electricity generation in MWh |

This monthly generation series is used as the high-frequency indicator for Chow–Lin and Fernández sensitivity specifications. Denton–Cholette baseline disaggregation does not use the indicator.

## 3. Temporal-disaggregation output variables

Validated public reference files:

- `results/01_monthlyization/Monthlyization_SA_results.xlsx`
- `results/01_monthlyization/Monthlyization_BM_results.xlsx`

The target monthly window is **April 2016 through December 2024**.

Important output series include:

| Output | Description |
|---|---|
| `Energia_MES` | Monthly generation carried forward for financial analysis |
| `Receita_Vendas_MES_DC` | Monthly sales revenue, Denton–Cholette baseline |
| `Receita_Vendas_MES_CL` | Monthly sales revenue, Chow–Lin sensitivity |
| `Receita_Vendas_MES_FERN` | Monthly sales revenue, Fernández sensitivity |
| `Energia_Comprada_MES_DC` | Monthly purchased-energy flow, Denton–Cholette |
| `Energia_Comprada_MES_CL` | Monthly purchased-energy flow, Chow–Lin |
| `Energia_Comprada_MES_FERN` | Monthly purchased-energy flow, Fernández |
| `Receita_Liquida_MES_DC` | Net revenue derived from monthly sales revenue minus standardized purchased-energy cost, Denton–Cholette |
| `Receita_Liquida_MES_CL` | Same concept under Chow–Lin |
| `Receita_Liquida_MES_FERN` | Same concept under Fernández |

The workbook also contains reconciliation, continuity, sign, non-positive-value, sensitivity, and method-audit sheets.

## 4. Financial-transmission derived variables

The public financial script reads the validated Module 01 reference workbooks.

Primary model-data variables:

| Variable | Description |
|---|---|
| `Usina` | Plant code |
| `Data` | Monthly date |
| `Valor_RV` | Monthly sales revenue under the selected temporal-disaggregation method |
| `Energia_Base` | Monthly electricity generation |
| `Preco_impl_bruto` | Raw implicit-price proxy: `Sales Revenue / Generation` |
| `P_ma3` | Three-month right-aligned moving average of the raw implicit-price proxy |
| `P_ma3_L1` | One-month lag of `P_ma3` |
| `ln_RV` | Natural logarithm of monthly sales revenue |
| `ln_E` | Natural logarithm of monthly generation |
| `ln_P` | Natural logarithm of the lagged smoothed implicit-price proxy |
| `Mes` | Calendar month number |
| `D_m1`–`D_m11` | Month fixed-effect indicators; December is the omitted reference month |

The implicit-price variable is an **accounting proxy constructed from prior sales revenue per unit generation**. It is not an exogenous market-price series.

## 5. Revenue-at-Risk output fields

The financial result workbooks contain both signed revenue change and loss-oriented reporting conventions.

| Field | Definition |
|---|---|
| `Beta` | Estimated generation-to-sales-revenue elasticity |
| `RevenueChange_10pct` | `100 × (0.90^Beta − 1)` |
| `RaR10_Loss_pct` | `100 × (1 − 0.90^Beta)` |
| `Significant_5pct` | Whether the primary generation elasticity is significant at 5% |
| `Effect_Interpretation` | Interpretation conditional on sign and statistical support |
| `Risk_Class` | Loss classification used by the reproducibility output |

A positive `RaR10_Loss_pct` represents a modeled revenue loss. A non-significant generation elasticity is not interpreted as evidence of a financial benefit, even when the raw signed transformation is positive.

## 6. Source institutions

| Data family | Source |
|---|---|
| Electricity generation and turbine flow | Operador Nacional do Sistema Elétrico (ONS) |
| Precipitation | Agência Nacional de Águas e Saneamento Básico (ANA), HidroWeb |
| Air temperature | Brazilian Air Force / Instituto de Controle do Espaço Aéreo (ICEA), CLIMAER Surface |
| Active fire hotspots | Instituto Nacional de Pesquisas Espaciais (INPE), Programa Queimadas |
| Santo Antônio financial data | Santo Antônio Energia public financial statements |
| Belo Monte financial data | Norte Energia S.A. public financial statements |

Original provider metadata and source terms should be consulted when interpreting source units or redistributing source-derived data.
